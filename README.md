# Freelancer CRM

**Client, project, proposal, invoice, and workflow management software for freelancers and solo service businesses.**

Freelancer CRM is a local-first business application designed to bring the full freelance operating workflow into one place:

**Lead → Client → Project → Proposal → Contract → Tasks → Time & Expenses → Invoice → Payment Record → Client History**

> This repository is a **public product showcase only**. The commercial application source code is kept private.

## The Problem

Freelancers and solo service businesses often manage leads, clients, proposals, contracts, projects, tasks, time, expenses, invoices, and payments across too many disconnected tools.

Freelancer CRM brings those workflows into one structured workspace so business activity is easier to track from first contact through payment.

## Core Features

- Lead pipeline and lead-to-client conversion
- Client records with project, proposal, invoice, and payment history
- Project management with budgets, billing models, due dates, tasks, time, and expenses
- Proposal creation with line items, discounts, tax, totals, expiration, and acceptance
- Contract records with terms and acknowledgment status
- Task views for today, upcoming, overdue, project-based, and completed work
- Manual time tracking and billable expense records
- Invoice generation with fixed fees, time, expenses, partial payments, credits, and balances
- Printable proposals, contracts, invoices, and payment records
- Reports for revenue, invoiced vs paid, outstanding balances, billable hours, effective hourly rate, lead conversion, proposal acceptance, and project status
- JSON backup/export and import
- Automated tests around money, workflows, invoice state, reporting, and persistence

- React

- Plain CSS

A separate React Native mobile companion has also been developed for mobile client and project workflows.

## Product Direction

The current version is intentionally local-first. Future commercial additions could include hosted data, authentication, team accounts, cloud sync, client portals, proposal sending, contract signing, payment integrations, automated reminders, and deeper financial reporting.

## Commercial Use

This repository demonstrates the product interface, workflow design, business logic, and development capabilities without distributing the commercial source code.
